# Curiouser

*Get curiouser before breakfast.*

Curiouser is a small Android app that delivers one idea a day, told as a true story, at 7am. It ranges across fifteen topics, from science and history to art, money, language and medicine, so it widens what you know rather than feeding a bubble.

- **Drink Me** shrinks the day's story to its one-line idea.
- **Eat Me** grows it back, and from the full story takes you down the rabbit hole into a deeper dive.
- **Through the Looking-Glass** gives the other side of the idea: its strongest objection, an honest "there isn't one", or a myth debunked.
- **The Red Queen's race** (before you begin): each story opens with a question about an earlier one, because trying to recall something fixes it in memory better than rereading.
- **The Hatter's watch**: a forgiving reading streak. A day counts when you finish a story or use Drink Me, and once a week a Hatter's Hour stops the clock on a missed day. It also shows weeks in a row (one story a week keeps it going) and the total days read.
- **Jars**: save ideas into named collections, starting with Orange Marmalade.
- **The Caucus-race**: a five-question quiz each Sunday on the week's stories. Everyone who finishes gets a prize.
- **Start here**: new readers begin with No. 0, the true story of how *Alice* was written, with margin notes explaining each feature and where its name comes from.

## Install (Android)

On your phone, open **[the latest release](https://github.com/TuckyPsyc/curiouser/releases/latest)** and tap `curiouser.apk`. If asked, allow your browser to install unknown apps. New stories arrive automatically.

## How it works

| Folder | What's in it |
|---|---|
| `content/issues/` | One JSON file per story. See [CONTENT_GUIDE.md](CONTENT_GUIDE.md). |
| `content/checks/` | The fact-checker's verdict on each story. A story reaches readers only once it has one. |
| `content/feed.json`, `content/published/` | Generated by `node scripts/build-feed.mjs` from the released stories; the app fetches these. |
| `agents/` | Instructions for each scheduled agent. Start with [agents/README.md](agents/README.md). |
| `videos/` | The Producer's video scripts, one per story, and `voice.json`, which chooses the narrator. The videos themselves are attached to the "Videos" release. |
| `reports/` | The Analyst's weekly reports, and a proposal on counting use without watching readers. |
| `marketing/` | The Marketing agent's weekly briefs, its notebook, the post results Carl reports, and `playbook.md`, which sets the Producer's style. |
| `support/` | How Curiouser writes back to readers: the tone guide and the FAQ. |
| `IDEAS.md` | The Developer's backlog, in order. |
| `src/` | The Expo / React Native app. |
| `.github/workflows/` | `update.yml` sends screen and feature changes to installed phones over the air; `android.yml` builds a new APK only when native-level files change. `desk.yml` keeps the editor's desk up to date, `release.yml` is Carl's override to publish a story, `video.yml` makes the daily video, and `checks.yml` tests every change. |

Deliberate shortcuts and what to change before growing beyond friends are in [DECISIONS.md](DECISIONS.md).

## Developing

```bash
npm install
node scripts/build-feed.mjs   # validate stories, regenerate feed and bundled seed
node scripts/test-gate.mjs    # prove an unchecked story can't reach readers
node scripts/stats.mjs --no-save   # the week's numbers, as the Analyst sees them
npx tsc --noEmit              # typecheck
npx expo start                # run in Expo Go / a dev build
```

To make a video by hand (the real ones are made on GitHub): `pip install -r scripts/video/requirements.txt`, then `python scripts/video/render.py videos/0001.json --out out`. It needs ffmpeg. `python scripts/video/selftest.py` tests the renderer.

Illustrations are John Tenniel's original engravings for *Alice's Adventures in Wonderland* (1865) and *Through the Looking-Glass* (1871), which are in the public domain, from [Standard Ebooks](https://standardebooks.org/)' scans. Nothing here uses Disney's designs. The app icon is original.

Videos are narrated by an AI voice, Kokoro v1.0 (Apache-2.0), and say so on screen. See [DECISIONS.md](DECISIONS.md), D-015.

Type is IM Fell English, digitised by Igino Marini, and Literata, both under the SIL Open Font Licence.
