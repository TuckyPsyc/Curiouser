# Curiouser

*Get curiouser before breakfast.*

Curiouser is a small Android app that delivers one idea a day, told as a true story, at 7am. It ranges across fifteen topics, from science and history to art, money, language and medicine, so it widens what you know rather than feeding a bubble.

- **Drink Me** shrinks the day's story to its one-line idea.
- **Eat Me** grows it back, and from the full story takes you down the rabbit hole into a deeper dive.
- **Through the Looking-Glass** gives the other side of the idea: its strongest objection, an honest "there isn't one", or a myth debunked.
- **Before you begin**: each story opens with a question about an earlier one, because trying to recall something fixes it in memory better than rereading.

## Install (Android)

On your phone, open **[the latest release](https://github.com/TuckyPsyc/curiouser/releases/latest)** and tap `curiouser.apk`. If asked, allow your browser to install unknown apps. New stories arrive automatically.

## How it works

| Folder | What's in it |
|---|---|
| `content/issues/` | One JSON file per story. See [CONTENT_GUIDE.md](CONTENT_GUIDE.md). |
| `content/feed.json`, `content/published/` | Generated by `node scripts/build-feed.mjs`; the app fetches these. |
| `src/` | The Expo / React Native app. |
| `.github/workflows/` | `update.yml` sends screen and feature changes to installed phones over the air; `android.yml` builds a new APK only when native-level files change. |

Deliberate shortcuts and what to change before growing beyond friends are in [DECISIONS.md](DECISIONS.md).

## Developing

```bash
npm install
node scripts/build-feed.mjs   # validate stories, regenerate feed and bundled seed
npx tsc --noEmit              # typecheck
npx expo start                # run in Expo Go / a dev build
```

Stories are written in [Lewis Carroll's](https://en.wikipedia.org/wiki/Lewis_Carroll) spirit but the artwork is original; nothing here uses Disney's designs.
